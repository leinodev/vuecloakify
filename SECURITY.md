# Security policy

## Supported versions

Until the first stable release, security fixes are provided for the latest
published version only.

## Reporting a vulnerability

Please use GitHub's private security-advisory flow for
`leinodev/vuecloakify`. Do not open a public issue for an unpatched
vulnerability.

Include the affected version, a minimal reproduction, the expected impact, and
any suggested mitigation. You should receive an acknowledgement within seven
days.
